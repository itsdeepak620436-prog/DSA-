## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/itsdeepak620436-prog/DSA-.git
   ```

2. Open the project folder in VS Code.

3. Navigate to the Java file you want to run.

4. Compile and execute the program using the terminal. For example:

   bash
   javac Deletion.java
   java Deletion
   

   Make sure you run these commands from the directory containing `Deletion.java`.
